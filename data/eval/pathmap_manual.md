# pathmap_manual.csv — 사람이 만든 2겹 경로표

`pathmap.csv` 는 절 본문에서 기계적으로 뽑은 것이라 특징 없는 절을 못 짚는다.
이 파일은 그 빈자리를 사람이 채운 것이다. `ONBOARDING.md` 8장 명세를 따랐다.

작성 2026-09-01 · 5절 · drydye

---

# 1. 어떻게 만들었나

`ONBOARDING.md` 8.5 의 다섯 걸음을 그대로 밟았다. 다만 3단계에서 낱말을
고를 때 눈대중으로 하지 않고 재서 골랐다.

```
1  절 본문을 읽는다                    원문 XML 을 목차로 잘라 읽었다
2  그 절로 와야 할 질의를 적는다          평가 질의가 아니라 일반적 표현으로
3  질의를 형태소로 쪼갠다                src/query.py 와 같은 tokenize 를 썼다
4  낱말마다 변별력을 잰다                아래 2절
5  점수를 매기고 행으로 적는다
```

## 왜 재서 골랐나

`pathmap_review.md` 에 적힌 `이유` 사고를 피하기 위해서다. `I/5 정관에 관한
사항` 에 `이유` 가 21.3점으로 들어가 실적 질의가 정관 절로 끌려갔다.
사람이 넣는 낱말도 같은 일을 낼 수 있다.

---

# 2. 변별력을 어떻게 쟀나

`pathmap.csv` 의 점수 정의를 그대로 썼다.

```
점수 = (그 절에 나오는 비율) ÷ (전체 절에 나오는 비율)
```

측정 대상은 2025 사업보고서 비금융 30개사를 목차로 자른 3,789절이다.
`src/search.py` 의 `tokenize` 로 쪼갰다. 파트너가 온보딩에 적은 값과 대조해
같은 자를 쓰고 있는지 확인했다.

| 낱말 | 이 측정 | 온보딩 기재값 |
|---|---:|---:|
| 실적 | 10.1% | 9.7% |
| 부문 | 12.9% | 12.9% |
| 개요 | 3.9% | 5.4% |
| 사업 | 27.3% | 39.8% |
| 회사 | 37.4% | 45.3% |

앞의 셋은 근접하고 뒤의 둘이 낮다. 표본이 30개사 사업보고서뿐이고 온보딩은
전체 절 108,337개 기준이라 그렇다. 순위를 매기는 데는 지장이 없다고 봤다.

## 딴 데 몰리는 절을 함께 봤다

전체 출현율이 낮아도 다른 절에 더 몰리면 쓰면 안 된다. 실제로 그런 것이 많았다.

```
사업부문   II/1 60%   그런데 VIII/1 80% · II/3 69%
영위      II/1 60%   그런데 I/5 97%          정관에 "영위" 가 많다
요인      IV/3 40%   그런데 IV/1 90%
영업이익   IV/3 93%   그런데 III/2/2-2 93% · III/4/4-2 90%   손익계산서
```

이런 낱말은 점수를 낮춰 거들기로만 쓰거나 뺐다.

다만 충돌 판정은 `pathmap.csv` 에 행이 있는 절만 대상으로 했다. `III/2` ·
`III/4` · `III/5` 는 행이 없어 `guess_paths()` 에서 경쟁하지 않는다.

# 3. 점수 배분

`ONBOARDING.md` 8.3 의 세 층을 따랐다. 문턱 15.0 기준이다.

```
혼자 확정   16.0 ~ 25.0   해당 없음. 그만큼 확실한 낱말이 없었다
짝이 필요   8.0 ~ 12.0    주력 · 영위 · 개요 · 진단 · 원인 · 증감 · 전년 · 실적
거들기      3.0 ~ 6.0     사업 · 부문 · 영역 · 대비 · 요인 · 경영
```

혼자 문턱을 넘는 낱말을 하나도 두지 않았다. 이 다섯 절은 전부 일반어로 이루어져
있어 한 낱말로 확정할 수 있는 것이 없었기 때문이다. `pathmap_review.csv` 가
겨냥하는 문제를 새로 만들지 않으려는 뜻도 있다.

절당 4~8개로 제한했다. 8.6 의 "절당 6~12개" 안이다.

# 4. 무엇이 달라지나

`guess_paths()` 만 떼어 재봤다. 검색 성적이 아니라 층 2 가 정답 절을 짚는지만
본 값이다.

```
평가 사례 37건 (data/eval/body_cases.csv)

기존      맞음 5 · 틀림 3 · 안 짚음 29
추가 후    맞음 7 · 틀림 4 · 안 짚음 26
```

오탐 점검도 했다. 다른 절이 정답인 질의 10개를 넣어 새 행 때문에 엉뚱한 절이
끼는지 봤다. 변화 없었다.

```
주주환원 정책 · 임원 보수 · 최대주주 · 배당성향 · 계열회사
소송 진행 · 자기주식 보유 · 감사의견 · 이사회 인원 · 정관 변경 이유
```

실제 검색 성적은 `python scripts/eval_body.py --mode=path` 로 재야 한다.
이쪽에는 DB 가 없어 못 돌렸다.

# 5. 못 한 것

## 5-1. `IV` 는 낱말을 넣어도 효과가 없다

`ONBOARDING.md` 8.4 에 "`IV` 는 예외다. 아래 소절이 없어서 `IV` 자체가 답이
되는 절이다" 라고 적혀 있는데 실측과 어긋난다.

```
2025 사업보고서 69건 전수
   IV 하위 절     69건 전부 여섯 개 (IV/1 ~ IV/6)
   IV 본문 길이   0자가 67건 · 100자 이상 2건 (최대 102자)
```

`search.py` 의 `candidates()` 가 `char_len >= 100` 으로 거르므로 `IV` 조각은
69건 중 2건만 후보에 들어간다. 그리고 `grade()` 는 절 제목의 부분 일치로
채점하는데 `IV/3` 의 제목은 `3. 재무상태 및 영업실적` 이라 정답
`IV. 이사의 경영진단 및 분석의견` 과 안 걸린다.

그래서 아래 3건은 표를 어떻게 만들어도 실패로 남는다.

```
set1-10  신한지주   경영진단 의견을 설명해줘
set1-19  NC        실적 변화를 설명해주고 공시 안에서 그 이유를 찾아줘
set1-28  NAVER     경영진이 밝힌 사업 전망과 위험 요인을 설명해줘
```

이 표는 `IV/2` 와 `IV/3` 에 낱말을 넣었다. 위 3건 중 둘은 지금 `IV/2` 를
짚는데 정답이 `IV` 라 틀림으로 센다. 위 성적의 틀림 3 → 4 가 그것이다.

정하는 방법이 셋이다.

```
가  정답을 IV/2 나 IV/3 으로 고친다      정답지는 사용자가 만든 것이라 고칠 수 있다
나  grade 를 경로 접두 일치로 바꾼다      IV/3 이 IV 의 하위임을 인정한다
다  그대로 두고 3건을 못 찾는 것으로 인정   
```

가가 맞아 보인다. 사용자가 "경영진단 의견" 을 물으면 실제로 읽어야 할 것은
`IV/2 개요` 와 `IV/3 재무상태 및 영업실적` 이고 `IV` 는 목차 줄이다.
다만 정답지를 고치는 것은 평가 기준을 바꾸는 일이라 합의가 필요하다.

## 5-2. `II/1` 의 한 유형은 표로 안 잡힌다

`"어떤 사업을 하는 회사인지"` 는 남는 낱말이 `사업` `회사` 둘뿐이고 둘 다
전체 절의 27~37% 에 나온다. 점수를 올리면 그 낱말이 든 모든 질의가 `II/1` 로
끌려간다.

`ONBOARDING.md` 4번 답에 이미 적힌 한계다. 층 4 용어 확장이나 `PATH_MIN`
조정이 필요하다.

## 5-3. 형태소가 갈라 놓는 것

표에 적을 때 원형으로 적었다. 다만 질의에서 갈라지는 것을 표가 못 따라가는
경우가 있다.

```
"실적이 왜 이렇게 변했는지"   →  ['실적', '이렇', '변하']
```

`변하` 는 절 본문에 0% 로 나온다. 넣을 근거가 없어 안 넣었다. 그래서 이 질의는
`실적` 8.0 만 남아 문턱을 못 넘는다.

## 5-4. 재보지 못한 것

`scripts/eval_body.py` 는 `chunk.embedding_oa` 가 있어야 후보를 뽑는다.
이쪽 `corpus.db` 는 W5 이전 것이라 `section` · `chunk` 가 없다. 실제 검색
성적은 DB 가 있는 쪽에서 재야 한다.
