# 질의 테스트셋

W7 검색·라우팅을 만들고 검증하는 데 쓴다. 한 세트를 끝까지 쓴다.
걸음마다 질의를 새로 만들면 기준이 흔들려 앞뒤 결과를 견줄 수 없다.

## 왜 사용자가 만드는가

AI 가 만들면 편향이 들어간다. 세 가지가 생긴다.

```
1  답이 있는 것만 묻게 된다
     조각을 읽고 질의를 만드니 자연스럽게 그렇게 된다

2  구현한 구조에 맞춰 묻게 된다
     담아둔 항목 26종 안에서만 묻는다

3  약한 곳을 피해 간다
     어디가 약한지 아니까 무의식적으로 건드리지 않는다
```

실제 평가자는 데이터 구조를 모른 채 묻는다. 그 조건에 가깝게 만들려면
데이터를 만들지 않은 쪽이 질의를 만들어야 한다.

## 채우는 법

`queries.csv` 의 `질의` 칸에 자연어 질문을 적는다.

```
질의      실제 평가에 나올 법한 문장. 기업명·기간을 넣어도 되고 안 넣어도 된다
난이도    하 · 중 · 상.  주관으로 적으면 된다
비고      의도한 것이 있으면. 없으면 비워도 된다
```

`정답` 칸은 없다. AI 가 각 질의를 받아 데이터에 답이 있는지 확인해 따로 채운다.
질의를 만드는 사람과 답을 확인하는 사람을 나누기 위해서다.

## 무엇을 물으면 좋은가

정해진 비율은 없다. 자연스럽게 섞으시면 그만큼이 우리 데이터의 실제 모습이다.

다만 답할 수 없는 질의도 넣어 주시면 좋겠다. 평가지표 7번이 그것을 본다.

```
지표 7  보유 데이터로 답변할 수 없는 질의를 식별하고,
        무리한 답변 대신 한계 고지 또는 역질문으로 대응하는가
```

답할 수 없는 경우가 네 갈래로 정의돼 있다. `DECISIONS.md` 2026-08-14 참조.

```
out_of_scope     범위 밖. 코퍼스 70개사가 아닌 기업 등
no_document      문서가 없다
not_disclosed    문서는 있는데 그 항목이 안 적혀 있다
extract_failed   우리가 못 읽었다
```

## 재료

```
기업        70곳. corpus.db 의 company 테이블
기간        2023 ~ 2026년
문서 종류    사업보고서 · 반기보고서 · 분기보고서
            주요사항보고서 · 거래소 계약공시 · 지분공시
```

## 참고용 질의 (주최 측 제공)

실제 평가 데이터셋은 비공개이고 아래는 예시다.

| 유형 | 질의 |
|---|---|
| 검색·추출 Closed | "OO기업의 2025년 연결기준 매출액은 얼마인가?" |
| 검색·추출 Open | "OO기업의 2026년 1분기 분기보고서를 기준으로 주요 투자 계획을 정리해줘" |
| 비교·연산 Closed | "2차전지 기업 A와 B 중 2025년 설비투자 규모가 더 큰 기업은 어디인가?" |
| 비교·연산 Open | "OO기업이 2025년에 실시한 자금조달 내역을 유형별로 정리해줘" |
| 복합 추론 Closed | "OO기업이 2025년에 체결한 주요 계약 이후 해지된 계약이 존재하는가?" |
| 복합 추론 Open | "OO기업의 2023년 사업보고서와 2025년 사업보고서를 비교했을 때 핵심 사업은 어떻게 변화했는지 설명해줘" |
