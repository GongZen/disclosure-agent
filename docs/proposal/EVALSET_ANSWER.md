## 답변 양식

모든 답변이 같은 순서를 따른다. 순서가 흔들리면 few-shot 으로 작동하지 않는다.

```
[결론]   한 문장. 질문에 직접 답한다
[근거]   항목 = 값 (단위 · 연결/별도 · 기준기간). 값마다 기준을 붙인다
[산출]   계산이 있을 때만. 식과 결과를 함께 쓴다
[유의]   한계·주의가 있을 때만. 없으면 블록 자체를 생략한다
```

되묻는 문장은 두지 않는다. `docs/PLAN.md` W8 과 `docs/PIPELINE.md` S10 이 금지한다.
되물으면 그 질의의 답이 없으므로 대신 후보를 전부 제시한다. 문항 14 가 그 사례다.

확인되지 않는 것은 확인되지 않는다고 적는다. 지표 7 정보한계 대응의 채점 대상이다.
