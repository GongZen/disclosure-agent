## ① 소스코드

과제가 요구한 것은 구현체, 재현 가능한 개발 환경 정의, 그리고 환경 구성과
실행 명령어가 담긴 README 다.

| 요구 항목 | 파일 |
|---|---|
| 구현체 | `src/` |
| 개발 환경 정의 | `Dockerfile` · `requirements.txt` |
| 환경 구성 · 실행 명령어 | `README.md` |
| 열쇠 서식 | `env.example` (실제 열쇠는 저장소에 없다) |

`src/` 의 주요 파일이다.

| 파일 | 하는 일 |
|---|---|
| `server.py` | 평가용 API 서버. FastAPI |
| `answer.py` | 질의를 받아 검색·생성·검증을 조립하고 네 필드를 만든다 |
| `query.py` | 질의 해석. 기업·연도·보고서 종류·업종·검색어를 가른다 |
| `retrieval.py` | 낱말 검색과 의미 검색을 합치고 매칭표로 절을 짚는다 |
| `facts.py` | 재무제표 정형 표에서 값을 직접 조회한다 |
| `events.py` | 수시·거래소·지분 공시를 정형 표에서 직접 조회한다 |
| `build_*.py` | 공시 원문을 데이터베이스로 적재한다 |

### 실행

저장소 뿌리에서 한다. 자세한 절차는 `README.md` 에 있다.

```bash
pip install -r requirements.txt
cp env.example .env          # 값을 채운다
python -m uvicorn src.server:app --host 0.0.0.0 --port 8000
```

컨테이너로 띄우려면 `Dockerfile` 을 쓴다.

### 저장소에 없는 것

| 항목 | 왜 없나 | 어떻게 하나 |
|---|---|---|
| `assets/` 공시 원문 5.3GB | 주최측 배포본이라 재배포하지 않는다 | 배포본을 받아 `assets/` 아래에 둔다 |
| `data/corpus.db` 5.6GB | 빌드 산출물이다 | `docs/SCHEMA.md` 의 파일 구성대로 다시 만든다 |
| `.env` | 열쇠는 저장소에 올리지 않는다 | `env.example` 을 복사해 값을 채운다 |

## ③ 평가용 API 서버 정보

```
End-point   http://211.188.57.111:8000
평가 창구    GET /answer?question_id={id}&question={평가 질의}
운영 기간    2026.09.07 ~ 09.20 상시
```

요청·응답 JSON 스키마와 사용법은 `제출물/API_서버정보.md` 에 있다. 단계별
설명과 실측 응답 시간까지 담은 전체 명세는 `docs/API.md` 다.

서버가 살아 있으면 아래에서도 볼 수 있다. 코드에서 자동으로 만들어지므로
실제로 도는 서버와 항상 일치한다.

```
http://211.188.57.111:8000/docs          사람이 보는 명세 화면
http://211.188.57.111:8000/openapi.json  기계가 읽는 명세 원본
```
