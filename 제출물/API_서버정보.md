## End-point

```
http://211.188.57.111:8000
```

| 항목 | 값 |
|---|---|
| 평가 창구 | `GET /answer` |
| 프로토콜 | HTTP |
| 인증 | 없음. 열쇠 없이 호출한다 |
| 운영 기간 | 2026.09.07 ~ 09.20 상시 |
| 호스팅 | 네이버 클라우드 플랫폼 · Windows Server 2022 |

서버가 재부팅돼도 작업 스케줄러가 API 를 다시 띄운다. 사람이 로그인하지 않은
상태에서 28초 만에 자력 복귀하는 것을 확인했다.

## 요청

```
GET http://211.188.57.111:8000/answer
    ?question={평가 질의}
    &question_id={식별자}
    &trace={text|json}
```

| 이름 | 필수 | 기본값 | 뜻 |
|---|---|---|---|
| `question` | 필수 | 없음 | 평가 질의. 한국어 문장 |
| `question_id` | 선택 | 빈 문자열 | 질의 식별자. 받은 값을 응답에 그대로 돌려준다 |
| `trace` | 선택 | `text` | `think_trace` 형식. `text` 는 한 덩어리 글, `json` 은 단계별 구조 |

`question` 에 한글과 띄어쓰기가 들어가므로 URL 인코딩이 필요하다.

### cURL

```bash
curl -G "http://211.188.57.111:8000/answer" \
  --data-urlencode "question_id=Q-001" \
  --data-urlencode "question=삼성전자의 2025년 연결기준 매출액은 얼마인가"
```

### Python

```python
import requests

resp = requests.get(
    "http://211.188.57.111:8000/answer",
    params={"question_id": "Q-001",
            "question": "삼성전자의 2025년 연결기준 매출액은 얼마인가"},
    timeout=120,
)
result = resp.json()
print(result["answer"])
```

## 응답

`Content-Type: application/json; charset=utf-8`

한글은 escape 하지 않고 그대로 보낸다.

```json
{
  "question_id": "Q-001",
  "question": "삼성전자의 2025년 연결기준 매출액은 얼마인가",
  "retrieved_context": "[값 1] 삼성전자 · 사업보고서 (2025.12) · 접수 2026-03-10 · 재무제표 표 조회\n삼성전자 2025년 매출액 (연결 · 연간) = 333,605,938,000,000 원 (333조 6,059억원)\n\n[근거 1] 삼성전자 사업보고서 (2025.12) · III/2/2-2 2-2. 연결 손익계산서 · 접수 2026-03-10\n연결 손익계산서 제 57 기 …",
  "think_trace": "S1 질의 해석 :: {\"초\": 0.0, \"기업\": [\"삼성전자\"], …}\nS3 후보 구성 :: …",
  "answer": "삼성전자의 2025년 연결기준 매출액은 333,605,938,000,000원입니다.\n\n근거:\n[값 1] 삼성전자 · 사업보고서 (2025.12) · 접수 2026-03-10 · 재무제표 표 조회"
}
```

| 필드 | 형 | 뜻 |
|---|---|---|
| `question_id` | string | 받은 식별자를 그대로 돌려준다. 안 주면 빈 문자열 |
| `question` | string | 받은 질의 원문 |
| `retrieved_context` | string | 답변 생성에 실제로 넣은 공시 원문. 6,000자에서 자른다 |
| `think_trace` | string 또는 array | 어떤 단계를 밟아 그 답에 이르렀는지. `trace=json` 이면 배열 |
| `answer` | string | 최종 답변. 끝에 근거로 삼은 공시를 밝힌다 |

### 근거의 세 층

`retrieved_context` 와 `answer` 의 출처 표시는 세 가지다.

| 표시 | 어디서 왔나 |
|---|---|
| `[값 N]` | 재무제표 정형 표 |
| `[공시 N]` | 수시·거래소·지분 공시 정형 표 |
| `[근거 N]` | 사업보고서 본문 |

---

## 답을 못 하는 경우에도 네 필드가 나간다

대상 기업을 못 찾거나, 근거를 못 찾거나, 생성이 실패하거나, 처리 중 오류가
나도 HTTP 200 과 네 필드를 보낸다. `answer` 에 왜 못 했는지 적고
`think_trace` 마지막 항목에 사유를 남긴다.

평가 중 한 질의가 실패해도 나머지가 이어지도록 하기 위해서다. 오류를 HTTP
상태 코드로 알리면 평가 도구가 그 자리에서 멈출 수 있다.

## 그 밖의 창구

| 경로 | 쓰임 |
|---|---|
| `GET /health` | 살아 있는지 확인. `{"ok": true}` |
| `GET /docs` | 사람이 보는 명세 화면. 여기서 바로 질의를 던져 볼 수 있다 |
| `GET /openapi.json` | 기계가 읽는 명세 원본 (OpenAPI 3.1) |

`/docs` 와 `/openapi.json` 은 코드에서 자동으로 만들어진다. 실제로 도는
서버와 항상 일치한다.

## 응답 시간

2026-09-06 실측. 외부에서 호출한 값이다.

| 질의 성격 | 예시 | 걸린 시간 |
|---|---|---|
| 정형 숫자 | 삼성전자의 2025년 주당 현금배당금은 얼마인가 | 2.3초 |
| 공시 조회 | 삼성전자가 2025년 7월 28일 공시한 공급계약의 계약금액은 | 3.5초 |
| 정성 서술 | SK하이닉스의 배당 정책을 알려줘 | 9.5초 |
| 살아 있는지 | `/health` | 0.12초 |

자체 평가지 28문항을 잇달아 던졌을 때 평균 8.4초, 최대 31.0초였다. 호출 측
시간 제한은 120초를 권한다.

## 답변 규칙

과제의 데이터 활용 규칙을 따른다.

- 답변은 제공된 공시 데이터만을 근거로 만든다.
- 모든 답변 끝에 근거 공시를 밝힌다. 회사·보고서·절·접수일을 적는다.
- 공시에서 확인할 수 없으면 확인되지 않는다고 적는다. 추측하지 않는다.
- 주가 전망·투자 추천·매수 매도 의견은 만들지 않는다.

마지막 항목에 해당하는 질의를 받으면 답을 거절하고 그 이유를 밝힌다. 오류가
아니라 설계된 동작이다.
